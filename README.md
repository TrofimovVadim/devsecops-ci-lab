# 🛡️ Автоматизация контроля безопасности кода (DevSecOps Pipeline)

Учебный проект (демонстрационный стенд), реализующий автоматическую проверку программного кода на наличие утечек конфиденциальных данных и уязвимостей при каждом изменении в репозитории.

## 🎯 Цель проекта
Исключить попадание паролей, API-ключей и небезопасного кода в основную ветку проекта за счёт внедрения автоматических проверок на этапе разработки (CI/CD).

## 🛠 Стек технологий и инструменты
* **GitHub Actions** — оркестрация и автоматический запуск проверок при событиях `push` и `pull_request`.
* **Gitleaks** — сканер для поиска случайно зашитых в код паролей, токенов и ключей доступа (Secret Scanning).
* **Semgrep** *(или укажи свой сканер)* — статический анализатор кода (SAST) для поиска логических уязвимостей.
* **Dependabot** — автоматический мониторинг уязвимостей в используемых библиотеках (SCA).

## 📂 Структура проекта
* ` config.py ` - тестовый модуль на Python.
* `.github/workflows/gitleaks.yml` — конфигурационный файл конвейера безопасности.

## 🚀 Как использовать в другом проекте
1. Скопировать файл `.github/workflows/gitleaks.yml` в свой репозиторий.
2. Включить **Dependabot alerts** в разделе `Settings -> Code security`.
3. При каждом `git push` проверка будет запускаться автоматически во вкладке **Actions**.
